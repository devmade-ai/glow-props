Patterns

Reusable implementation patterns extracted from real projects. Each is documented with requirements, approach, alternatives considered, and key lessons. View full reference.

PWA System

Install prompts, service worker updates, offline support. Handles the beforeinstallprompt race condition and browser-specific install instructions.

  • vite-plugin-pwa
  • React hooks
  • Cross-browser

Theme & Dark Mode

User-controlled dark/light mode with system preference fallback, localStorage persistence, cross-tab sync, and flash prevention.

  • CSS variables
  • Tailwind v3/v4
  • React + React Native

Burger Menu

Accessible dropdown navigation using the WAI-ARIA disclosure pattern. iOS Safari backdrop fix, focus management, and z-index scale.

  • Disclosure pattern
  • React + React Native
  • Tailwind

App Icons from SVG

Single SVG source file converted to all PNG sizes at 400 DPI using Sharp. One command regenerates everything.

  • Sharp
  • 400 DPI rasterization
  • PWA manifest

Download as PDF

Zero-dependency PDF export using window.print(). Print-friendly CSS overrides, no-print utility class, and page break control.

  • window.print()
  • @media print
  • Zero dependencies

HTTPS Proxy Support

Zero-dependency HTTP CONNECT tunnel for Node.js scripts behind proxies. Transparent fallback to direct connections.

  • Node.js stdlib
  • HTTP CONNECT
  • Proxy auth

Debug System

In-memory event store with floating debug pill. Pub/sub circular buffer, severity levels, environment diagnostics. Renders in separate React root.

  • Pub/sub
  • Separate React root
  • Alpha diagnostic
